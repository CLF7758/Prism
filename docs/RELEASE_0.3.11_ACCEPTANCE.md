# 0.3.11 发布验收

日期：2026-10-16；环境：本机 Windows、Python 3.12、Qt 6。测试使用隔离目录和演示工程，不保存用户个人工程。

## 功能检查

| 范围 | 结果 |
| --- | --- |
| 下载节点、混合图文、原件、画质保护、视频封面、裁切及 PDF 相关回归 | 37 通过、2 跳过 |
| 显式启用 WebEngine 的 PDF 检查 | 5 通过，包含完整脑图结构 |

已发布 0.3.10 的 item_metadata.py 就包含 lastUsed；测试旧断言没有更新。本次保留对 EXIF／ICC 不被当成用户元数据索引的检查，只将 lastUsed 加入正确的字段集合。

独立的两条旧选择绘制测试仍按 drawRect 编写，而发布版使用 drawRoundedRect；未通过删除测试掩盖。它们不属于本次目标检查，不能据此声称整个仓库所有测试全绿。

## 原生界面

实际启动最新源码的 Prism，在原生 Windows 窗口查看：中文无方块；右键裁切出现四角和四边共八个圆点，边点可以拖动，回车提交；画布下载节点标题能够拖动。粘贴用户的抖音 qzZQ-wKMbzY 分享链接后，后台完成下载、两份素材插入画布并排列，节点自动消失，选中的旧图片未被抢走。Live Photo 可以启动播放，右侧首帧居中。

README 的画布、素材库、文档、脑图和查重截图来自原生 Qt 窗口；下载节点图由 Windows 窗口截图取得。公开截图仅使用程序生成的演示图形，用户下载作品的验收截图留在本机，不进入仓库。

## 打包检查

PyInstaller 主程序启动及冻结查重子进程通过。六个独立组件通过 Prism 正式的 process_bootstrap 启动路径，在独立暂存目录导入运行；OpenCLIP 权重 SHA-256 与固定值一致，Xhshow 源码和许可证存在。

另外使用打包目录内的 worker、Python、yt-dlp 和 FFmpeg，通过本地 HTTP 实际下载测试视频；下载文件、原件快照与源文件 SHA-256 完全相同。

Inno Setup 首次因暂存目录过深而失败，改为较短的独立目录重新编译。构建说明应使用短的 ComponentRoot，避免依赖头文件超出 Windows 路径长度限制。

未声称做过全新 Windows 虚拟机安装验收。平台实测文件尺寸和权限边界见 RELEASE_0.3.11.md。
