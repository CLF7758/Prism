# Eagle 风格侧栏

此调整仅作用于资源栏和素材检查器，保留画布与现有画布隔离规则。

左栏提供项目搜索、全项目口径的「全部素材 / 未标签」筛选、回收站和资源树。底部可展开评分及清除筛选。顶部的「Prism 图标 + Prism 文字 + 加号」品牌行（`libraryHeader`）与「标签管理」导航入口已按需求 5、需求 1 移除——新建页面/文件夹改由资源树右键菜单承担，标签管理器仍保留在资源树「标签」分区右键与素材右键菜单里。全部素材 / 未标签 / 回收站的数字都是全项目口径（方案 §5、§6），不再只统计当前画布；导航数量不计入文字与绘图注释；资源树中的画布文件夹汇总下属画布素材数量。资源行高 28 px，分区标题 32 px，供右键创建的空白行 14 px。

右栏按预览、色彩分布、名称、备注、可复制的本地源路径、评分、标签、所在画布与文件信息排列。标签胶囊自动换行，保留多选混合状态；加号展开查询与创建输入框。色彩分析按需求 3 恢复原「色彩分布条 + 名称 / 百分比」实现（`_cd_container`），移除 Eagle 风格的圆点色带（`_palette`）；点击所属画布定位页面。直方图逻辑保留在代码里但按方案 §8 默认隐藏，本次需求不擅自增加大块图表。
