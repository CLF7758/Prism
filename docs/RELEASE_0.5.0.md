# Prism 0.5.0

2026-11-04 · Windows x64 · 完整组件安装包

## 本版功能

- 增加并整合 FBX/OBJ/GLB/glTF 模型库：模型卡片、实际材质槽位、共用贴图管理、模型预览、封面、模型和贴图原件导出/外拖。
- 材质库与模型库采用同一 Babylon.js 预览链路和工作室 HDRI，保留各自亮度参数。
- 全部素材、未分类、未标签、最近使用和回收站统一覆盖图片、画布、文档、脑图、材质和模型；最近使用最多 100 项。
- 文件夹以列表浏览，具体画布仍使用无限画布；增加层级线、稳定的新建位置及移动目标选择。
- 图片单选复用完整素材检查器，显示所在画布/文件夹路径；点击位置按钮或双击跳转。刷新统计不能覆盖选中详情。
- Eagle 导入可以追加到当前工程，保留可读取的目录层级、备注、标星与标签，并生成视频封面与画布布局。
- 管理式工程使用 .prism 入口和 .prism.data 目录；完善保存、另存为、自动保存/恢复与原件管理。
- 多项后台预览、缓存、资源查询、计数、窗口生命周期和退出清理修复；包括暂停视频释放和 Windows 临时原件占用的退出异常保护。

## 完整安装内容

主程序、Qt/WebEngine、图像/视频依赖、截图组件、以图搜图运行时及 ViT-B-32 权重、通用视频下载和 F2/XHS/Bilibili 独立组件。用户无需另装 Python。在线平台功能仍依赖网络、账号权限和平台接口。

## 功能边界

- SSS/置换支持贴图资料管理，不承诺完整厚度散射或几何细分置换。
- 向 UE 拖出模型/贴图不自动创建 UE 材质球或母材质；导入结果取决于格式及 UE 设置。
- 原件导出保留原始文件；不能从缺失原件的旧项目中重建已经丢失的数据。
- 大型工程和首次网页预览仍有硬件相关成本。当前检查不等于所有显卡、机器和内容都已桌面验收。
- 未签名安装包；请以同页 SHA256.txt 验证。

## 安装与升级

安装 Prism-Setup-0.5.0-windows-x64.exe。更新前备份整个工程，搬迁时同时保留 .prism 入口与 .prism.data 目录。完整源码、构建脚本与第三方许可随本版本发布。
