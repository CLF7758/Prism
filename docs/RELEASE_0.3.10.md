# Prism 0.3.10

把参考图摆在画布上看、截图送进画布、把图片钉在桌面上对照创作，并在本地用图片查找相近素材。

## 安装

下载本页 `Prism-Setup-0.3.10-windows-x64.exe`。截图、搜索所需的运行环境和搜索模型随安装包提供，无需另装 Python 或填写 API。首次搜索需要建立索引。`Prism-0.3.10-source.zip` 是对应源码，`SHA256.txt` 用于核对下载文件。

## 本版更新

- 截图与桌面贴图接入开源 ScreenPinKit；画布图片可钉到桌面，支持透明度调整。
- 贴图复用主画布的紧凑标注工具，随窗口移动，切换目标时隐藏，并修复选择相关异常。
- 搜索框加入以图搜图入口。使用 OpenCLIP、FAISS 和 OpenCV，在本地按内容、颜色与布局查找素材。
- 修复检索结果排列顺序、搜索区域布局与截图快捷键等待问题。
- 整理项目简介，保留原有演示图片。

## 已知限制

网站视频下载尚未修复，本版不作为可用功能推荐，后续版本继续处理。图像相似度是检索排序依据，不是“风格一致”的保证；大量素材的首次索引仍需等待。安装包未数字签名。
