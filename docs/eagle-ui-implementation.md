## 关键实现

`prism/widgets/asset_browser.py` 使用 QListView 和委托绘制，避免为全项目的每张图创建单独控件。已有 ProjectAssetCatalog 提供实际数据；可见缩略图使用现有异步解码服务。集合占用空间读取归档字节数，不解码原图。

智能文件夹保存为 prism_metadata.library_queries。最近使用时间保存为素材 metadata.lastUsed。既有回收站及删除时间结构保留。

参考项目有 1,562 条图片记录，其中一张不能解码。归档来源的错误占位现在参与素材统计和回收站；保存及另存保留原始图片记录、字节和元数据，避免用假数字补齐总数。普通界面错误提示不计入素材。

## 独立三栏修正（2026-10-12）

本轮依据用户截图重新核对结构：左栏、中间区域和右栏现在是 splitter 内三个完整的纵向容器，每个容器拥有自己的顶部和内容。中间筛选栏和状态栏只占中间区域。置顶、最小化、最大化及关闭控件归属于右栏顶部。左上无加号和画布切换按钮。

删除了抽屉、遮罩及画布边缘悬浮展开按钮。折叠直接隐藏相应容器，让中间区域得到原侧栏宽度；重新展开恢复既有栏宽。右栏关闭时窗口控制临时停靠在中间区域右上方，保持可关闭窗口；打开右栏后自动回到右栏顶部。切换文档或脑图不改变侧栏折叠状态，图片详情内容在这些模式下隐藏。

通过 E:/eyes/Agent-Reach 的 Exa 检索与 Jina Reader 读取了官方说明：
https://cn.eagle.cool/support/article/how-to-independently-open-and-close-eagles-left-and-right-sidebars

官方说明核实了右键“左栏/右栏”图标分别控制两栏，以及 Windows 的 Ctrl+Alt+1、Ctrl+Alt+2、Ctrl+Alt+3 切换。本项目同时支持用户截图中的 Tab 双栏切换。截图用于核对视觉归属，网络工具用于核实操作行为。
