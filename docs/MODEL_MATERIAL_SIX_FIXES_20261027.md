# 模型材质侧栏六项问题修复记录

本轮按用户截图修复现有工作流，不改变原件。不操作桌面；界面与原生进程均离屏验证。

## 实际模型核查

只读核查 `Prism测试/Prism-100k-v1-新版.prism.data` 中的 `SM_FrontEntranceRoof.FBX`，将工程中的原件读取到临时工作包。

- 文件为 FBX 7.3。旧解析器按版本号把编码数组当作旧式数组，漏掉逐多边形材质索引。
- 修正后：14 个材质定义、42 个材质使用点，Assimp 几何可全部一一对应。原来错误显示为首个材质使用 3 处，其余均为 0。
- 该原件没有贴图声明；该模型的工程文件清单也只有 FBX。不能根据材质名推测或伪造图片绑定。界面明确提示可从材质库选择或手动添加。
- 实际原生进程完成该模型加载、第二个材质的使用点高亮请求、预览图输出。证据：`artifacts/model-material-roof-fix/result.json`、`roof-preview.png`。没有验证可见窗口的前台层级。

## 改动

1. 上框为材质球区域，下框为选中材质的贴图与参数。使用部位路径默认折叠，重复说明收起，按钮缩短。
2. 所有源材质均建立工作材质，包括没有部位使用的材质，因此均可选择和编辑。选择无使用点材质时清除旧高亮。
3. FBX 7.0—7.3 对编码数组按实际头部核验，保留旧式数组兼容；导入器同步修复。
4. 法线覆盖接通现有贴图控件与原生渲染器；法线强度和绿通道翻转沿用材质库语义。
5. 已加载模型的编辑在持久化前进行真实渲染校验；数据库提交失败恢复已提交预览。
6. 材质状态变化使球面缩略图缓存失效；快照替换后不重复列出同一工作材质的源定义。
7. 无请求回执的预览错误也显示在侧栏，避免只剩无响应的禁用控件。
