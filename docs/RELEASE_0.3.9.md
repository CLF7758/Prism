# Prism 0.3.9

本次更新集中于大画布显示、查重性能、原始数据保护和交互一致性。

## 显示与性能

- 素材记录与可见编辑图元分离，多级预览、异步解码及有界分块缓存。
- 滚轮交互不再强制退到 192 像素，保留可用的清晰显示层级。
- 补充视口粗覆盖，降低切换、跳转时露出背景的概率；实际显示仍受 GPU、素材格式和加载状态影响。
- 查重复用只读连接，使用受限后台进程计算大图原始指纹，持久保存指纹缓存。
- 同一开发机 2712 张图片副本，空指纹缓存首次扫描约 55 秒降到 21.4 秒；缓存复扫约 0.23 秒。全部指纹一致，44 组结果一致。未清空系统磁盘缓存，不代表冷盘或其他机器的通用性能。
- 操作日志、后台队列和显示缓存均有上限。

## 修复

- 橡皮擦拖动擦除笔画、箭头形状与撤销。
- F2 编辑保留原名、资源树和公共入口选中态同步。
- 所在画布和查重定位打开正确画布并选中图片。
- 标签直接输入，公共视图及标签视图临时标注在导航时清理。
- 素材排列排除笔画、箭头和文字；视频提取帧自动最优排列，整批支持一次撤销。
- 从画布删除和撤销删除时，查重结果自动同步。
- 原图导出检查仅统计实际导出的未删除图片，不把视频和标注误报为图片原图缺失。
- 视频帧添加时保留完整无损 PNG，保存重开与导出保持数据一致。
- 二级窗口应用原生深色标题栏和边框配色，保留系统窗口操作。
- 移除画布 AI 打标签入口；安装包不包含打标签模型。
- 打包入口支持 multiprocessing 冻结进程引导，新增内部后台进程冒烟检查。

## 验证与范围

分阶段运行了架构、显示、查重、原图往返和交互回归。最后的原图针对性回归为 54 项通过，版本及进程相关发布检查为 12 项通过。EXE 的后台进程指纹一致性与启动检查另行执行。各轮测试有重叠，不作为独立总用例数相加。

扩大回归中三条原有失败已在修改前快照复现：元数据用例缺少已有 lastUsed 字段，两条 Windows 不可写目录用例在当前权限下未产生预期错误。没有删除或弱化这些测试。

尚未完成干净虚拟机、所有显卡、多显示器及真实数万种不同图片组合的完整验收。首次读取、构建预览和查重仍有成本；本次更新不能恢复已经不存在的原始文件。安装包未作代码签名，架构拆分仍在持续。升级前请保留重要项目备份。
