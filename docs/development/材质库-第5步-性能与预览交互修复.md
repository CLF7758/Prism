# 材质库：性能、预览形状、通道与整理导出

日期：2026-10-19。本轮按用户连续补充的第 1–16 点修订。以本说明为最新界面和交互规则。

## 调节卡顿

旧路径每次调整都刷新整份列表、编码全部缩略图，还生成 512px 渲染截图；120ms 的反复延迟在持续拖动时会一直推迟预览。现改为参数变化只更新引擎参数，33ms 合并连续输入，不重建列表。停止输入后再用独立相机/独立图层生成 256px 球体卡片，卡片只更新变化的图片 DOM。普通球体由 192 段降为 48 段，置换使用较密网格；隐藏预览停止常驻渲染。

四组用户真实素材连续 41 次参数事件测试，Python 事件处理平均约 1.2–2.5ms，无整列表刷新。该数值不是完整 GPU 帧时延，也不代表所有机器都达到固定帧率。

## 预览和单通道

右侧与大预览可切换平面、球体、圆柱、立方体。根据用户“默认屏幕”暂按正对屏幕的平面处理；中间卡片仍生成球体。立方体/圆柱提供可辨认形体的初始角度，可旋转、缩放和复位。

通道查看使用 Babylon 原生 PBR unlit 材质与独立图像处理配置；避免灯光、ACES 或错误的标准材质叠加将数据变白。测试不仅检查材质加载，还核对输入 130 的灰度在画面中心仍为约 130。可切换粗糙度、金属度、AO、透明、SSS、置换；原有颜色、法线、自发光映射继续支持。没有该通道时明确提示，不能假称有贴图。

切换页面时复用已经创建的 WebEngine 表面，不重新创建窗口或再次完整渲染；启动前共享 OpenGL 上下文，降低首次显示 WebEngine 时切换合成方式产生闪动的机会。测试验证多次切换仍使用同一组 WebEngine 实例。外部桌面合成器的全部行为不能单靠 Qt 实例断言保证。

## 右栏与颜色

- 颜色使用 MIT 开源 vcolorpicker 1.4.4 的 SV 方块、鼠标选择与色彩转换，Prism 做纵向布局、水平色相、HEX、常用颜色和应用/取消适配，不重写色彩选择核心。原始代码和许可证位于 prism/vendor/vcolorpicker；新增 QtPy 2.4.3 适配依赖，源码启动器会检查。
- 颜色、自发光、SSS 提供“复原颜色”，恢复白色乘色与强度 1。
- 移除整体和各槽位的水平/垂直翻转入口。既有项目保存的变换数据仍能读取，不擅自改写原图。
- 法线提供“翻转绿通道”，只反转 G，不反转 R/B。格式覆盖仍位于高级设置。
- 各槽位采用统一行高与间距；置换中点是独立标签与无箭头数值框，不再把长前缀塞进窄输入框。
- 整个槽位及其子控件都接收文件拖放，包括文件名、滑块附近和空白处，不再要求拖到十字中心。
- 标签和备注固定在右栏底部直接显示，不藏在页签。版本和文件详情另有页签。

## 中间列表与导出

搜索位于最上方；删除返回上一级/标题整行，隐藏原面包屑。新建材质和新建文件夹位于网格/列表工具栏。文件夹通过左侧目录导航。

普通点击单选，Ctrl 点击增加/取消选中。右栏编辑最后活动的材质；高亮全部所选卡片。右栏固定“导出原始贴图”按钮；卡片右键也能导出。多选时右键菜单显示所选数量，导出按钮按多选处理。

批量导出为每个有源文件的材质建立独立名称+编号文件夹，使用原附件字节，避免材质之间同名贴图覆盖。没有贴图的空草稿不生成无意义文件。文件名保留，内容不经过缩放、重编码或通道拆分。导出目标不会使用预览代理或材质球截图。
