# 材质库第 2 步：SurfaceStudio 卡片浏览与详情结构

日期：2026-10-19。

这一轮把之前的文字列表换成了实际运行的 SurfaceStudio 卡片网格，接到已有材质记录、工程保存和导航中。

## 用户现在能操作什么

- 默认多列卡片网格；卡片有预览位置、名称、资料类型、已知 UE 版本和前几个标签。
- 点击卡片会选中对应记录，右侧切换到同一条材质；支持 Enter、空格和方向键选择。
- 可以切换网格／列表，调整卡片大小；这些显示偏好随工程保存。
- 搜索名称、说明和标签；从右栏点标签也能筛选当前范围。
- 根入口显示全部记录；文件夹显示本级和子文件夹记录。子文件夹列表默认收起，分类仍以左栏为主。
- 切页面和文件夹后保留选择、搜索和滚动位置；换工程后旧网页消息不能选择新工程中的记录。
- 原有名称、说明编辑和存取继续使用；快速切换、重开工程时不会把旧表单写到新读入记录里。

## 右栏包含什么

顶部是材质效果区域，下面依次是名称、分类、资料类型、UE 版本、收集版本、默认模板、只读属性、标签、贴图明细、UE 原件情况和说明。

透明方式、金属、粗糙、法线、自发光和 SSS 读取已保存的展示资料；缺少的写“未提供”。贴图明细读取记录中的通道、文件名和实际尺寸，未知尺寸不猜测。

目前没有接入贴图收集和球体生成。因此：

- 草稿显示“待添加贴图”。
- 有贴图但没有生成球体图时显示“等待生成材质球”。
- 已有生成缩略图附件的记录可显示该图；它是缓存展示，不代表已经接通交互球体。
- 没有实时调材质参数的滑条。页面上的滑条只控制卡片大小。
- 没有放置暂时不能工作的“发送 UE”或“导入”按钮。

**卡片和详情结构完成不等于全部第一期完成。原图收存是下一步，贴图套球和八项效果按第 4 步接入。**

## 具体复用了什么

- 实际加载 `surface-studio/draw-cards.js` 中未修改的 SurfaceStudio `drawCards`、文字转义和数字格式化函数。
- 实际加载其原始 `style.css`，使用原始 SVG 图标。Prism 的颜色、选择和资料适配放在单独文件中。
- 通过 Prism 现有 QtWebEngine 和 QtWebChannel 连接网页卡片与项目记录。原件和记录仍由 Prism 的存取服务负责。
- 右栏沿用 Prism 的原有详情容器，按材质效果、版本、属性、标签和贴图分区适配，不启动另一个桌面程序。
- 保留 SurfaceStudio 原文件快照、GPL-3.0-only 许可证、作者说明及文件摘要，已登记到 `THIRD_PARTY.md`。

不加载 Blender 脚本，不启动 SurfaceStudio 原服务器，不在当前步骤增加第二套分类或文件存储。

## 验证

新增浏览器集成测试实际加载网页，检查 DOM 卡片、点击、选中高亮、键盘、网格／列表、卡片尺寸，以及右栏资料对应。

同时覆盖了来源文字和导入编号的 HTML 转义、旧工程浏览器消息失效、快速切换与真实工程保存、旧工程兼容等情况。相关回归结果为 **292 项通过、1 项跳过**，包含资源树、工作区迁移、SQLite、未保存提示、工程加载和画布操作；未执行全项目所有测试。
