# 自动预览、紧凑槽位与普通启动 WebGL 修复

日期：2026-10-19。本轮按用户最新要求，替代之前“点更新预览才渲染、不提供参数滑块”的交互。

## 修复的实际原因

原 document_panel.py、mindmap_panel.py 在导入时给 QTWEBENGINE_CHROMIUM_FLAGS 同时加入 `--disable-gpu --disable-software-rasterizer`。这不是只影响文本编辑器，而是禁用了整个共享 Chromium 的硬件及软件图形后端。因此普通启动无法预览；旧的 GPU 测试额外设置 `--no-sandbox`，绕过了这个默认配置，未能发现问题。

现在由 `prism/webengine_runtime.py` 统一设定默认参数，不再关闭两类渲染后端；__main__ 在导入 QtWebEngine 前调用，两个编辑器和材质预览使用同一设置。保留用户显式设置的环境变量。引擎直接尝试初始化，并显示真实初始化错误，去掉笼统的显卡不支持预判。修改必须完全退出旧进程并重启源码版后生效。

## 新界面与交互

右栏顶部固定名称、小球、自动透明判断、整体水平/垂直翻转，滚动下方槽位时仍能看见小球。下方以“贴图槽位”“标签与备注”切换。

槽位使用紧凑布局：折叠标题、启用开关、小贴图、文件名（完整名称和尺寸在提示中）、替换、清空、通道选择、复用、滑块和精确数值。颜色/自发光/SSS 提供颜色选择；标量提供反转；槽位提供独立翻转。置换提供位移范围与中点，不出现厚度入口。

原图仍从桌面或资源管理器直接拖入槽位，或点击小图选文件。关闭槽位不删除原图；翻转及反转也不修改原图。法线镜像时同步修正对应的向量分量。

数值语义：粗糙度/金属度无图使用常数，有图使用倍率；颜色使用乘色与强度；法线、自发光、SSS 等控制对应原生引擎强度。自发光未配置默认为 0，添加自发光贴图后默认为 1。槽位开关关闭时旁路该槽位效果。

## 自动更新和并发

贴图、通道、启用、数值、颜色及翻转变化后，合并 120ms 内连续事件，自动更新右侧和中间卡片，不需要更新按钮。按钮仅在失败时作为重试入口。

普通数值/颜色变化复用已解析的贴图，并直接更新 Babylon PBR 参数。换通道、反转、翻转或启停贴图才重新准备代理。每次请求携带材质 ID、项目服务、签名与 token；旧请求不会覆盖新参数或新项目。Babylon 截图排队执行，避免连续调节时并发修改渲染目标。

单独查看通道不改变材质接法；大预览同步同一材质的后续更新，保留相机角度及通道查看选择。卡片由右栏标准预览生成，大预览的自由视角不覆盖卡片。

## 自动透明

默认自动识别；高级设置允许强制纠正。优先分析透明槽选定的通道；没有透明槽时，检测已启用颜色图的有效 A 通道，可在高级设置忽略颜色 A。

全不透明使用不透明模式；以黑白为主、允许轮廓边缘灰阶的输入判为裁切；连续灰阶判为混合。透明强度小于 1 时自动使用混合。SSS 不是透明输入。来源已有明确模式时保留来源/已保存设置；旧项目的明确模式也保留，可在高级设置恢复自动。

这属于可纠正的启发式，不声称能从像素唯一还原作者意图。UI 提示判断结果和依据，不要求首次先选透明方式。

## 验证与原文件

新测试 `tests/test_material_auto.py` 覆盖透明判断、颜色图 A、禁用 Alpha、反转和翻转、参数缓存、默认 WebGL 参数、自动卡片更新和连续快速调节。原有原图存取测试继续校验项目保存、重读和原文件导出。不同名字但相同内容的文件保留各自原始名称。

`tests/_verify_material_auto_real_assets.py` 使用前一轮真实素材验收项目里的全部 14 张原图，不依赖外部源目录：四组逐一自动渲染，自动判断植物 R 为裁切，验证滑块、反转、颜色乘色和整体翻转，最后核对所有原图 SHA-256 不变。已通过，耗时约 68 秒。

实际测试项目：`artifacts/material-tests/真实素材-自动更新.prism`。这个项目保留了测试过程中修改过的乘色、粗糙度和翻转设置；原图未改变。原始效果基准仍在 `真实素材验收.prism`。界面截图：`material-library-real-assets-final.png`。

测试在原生 Windows 下移除了额外 QTWEBENGINE_CHROMIUM_FLAGS 后运行，使用程序自身默认设置。综合相关回归 132 passed、4 个原生 GPU 检查另跑；原生材质/编辑器检查 63 passed。

## 尚未改变的边界

SSS 仍使用 Babylon 原生薄表面 Burley 次表面透光；皮肤/蜡/玉石的完整体积散射尚未完成。压缩 GLB 的额外离线解码器不在本轮。UE 插件与任意 UE 母材质的逐像素一致性也不属于本次修复完成的范围。


固定预览与资料切换完成后，材质相关原生检查再次通过：36 passed；最终真实素材界面截图检查 1 passed。脚本还执行了 render.js 的 Node 语法检查。上述测试结果有重叠，不应相加当作独立用例总数。
