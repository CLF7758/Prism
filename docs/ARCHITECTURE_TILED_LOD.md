# Prism 分块 LOD 实施记录

修改已写入用户指定的 .github 项目源码，保留 ponytail-main 所倡导的职责分离；没有替换安装版 EXE。

## 已实施
- 新增 canvas_tiles.py：512 像素固定空间块、二倍层级、迟滞、160 毫秒淡入，优先复用父块；缩小时可合成已有子块。
- 图块缓存预算 64 MiB，包含过渡旧图；相机变化丢弃过期待办，中心优先并预取一圈邻区。每轮 GUI 构建预算 4 毫秒，但单次 Qt render 不可中断。
- 资源库画布与全部素材/标签等汇总画布接入共同图块模块。原图导出仍走独立原始数据路径。
- 图片完成解码后先等待可见预览齐备，再刷新相关图块；选中框与四角标识由独立覆盖层绘制。
- 总览群组选中保留轻量记录，不再为每张选中图片创建编辑图元；单图、裁剪、文字编辑及鼠标正在操作的对象继续保留编辑能力。
- 新增 image_pyramid.py：后台生成 32/64/192/512/1024 预览并缓存到单独 SQLite，预算 256 MiB（周期清理）。内容或来源文件版本变化产生新键。缓存可丢弃，不修改原图。

## 实际限制
本次是分块渲染、多级预览和编辑对象按需创建的核心改造，不是整个项目所有模块重写。旧版 image_for_view 仍保留给已有诊断测试，实际 paint 走分块路径。
未验收真实三万张不同格式图片、4K 多屏与目标 GPU 帧率。第一次大跳转到完全没有缓存的区域仍可能显示背景；单个重图块的 Qt 渲染也可能超出 4 毫秒预算。
