# Prism 新存储与强制转换：测试交接（2026-10-26 更新）

## 用户操作

从源码启动 BAT 重启程序后，打开旧版 `.prism` 会先说明存储升级、原文件保留和校验要求。点击确认后选择保存文件夹，生成 `原名称-新版.prism` 和对应数据目录；已有入口不覆盖。取消选位置会取消打开，不提供继续按旧格式编辑的入口。

先加载旧源的只读画布，实际 GUI 安装结束后才启动非模态后台转换。首版只读预览**限当前画布**：可拖动及滚轮缩放；资源导航、文档/脑图编辑器、编辑动作、保存/另存为/自动保存、导入、粘贴及撤销暂时禁用。该限制会明确显示，未宣称跨资源编辑器只读导航已实现。

转换进度窗取消只取消转换，继续保留只读预览并可重试；“结束预览”会先安全取消在途任务，再清空预览恢复操作。失败或入口缺失不切到不完整副本，旧源不改。成功后验证目标入口、工程身份和打开代次，实际新版安装成功后才解除门禁；当前画布相同则保留预览缩放和视角。旧回调不能替换其它工程。

**新工程与另存为默认结构已经改为：**

```
我的工程.prism        小型、有独立格式版本和工程身份的入口
我的工程.prism.data/  元数据、原件对象库、工作锁
```

新 `.prism` 入口不是原图容器。它与数据目录通过相对名称和 storage_instance_id 绑定。移动工程时必须把这两项一起移动，名称保持配套；分享可用导出便携包。已有 `.prismproj` 目录仍能打开。现阶段不支持只改入口文件名而不调整配套目录；需要更名时使用另存为。

新入口最后发布：原件复制/哈希与长度验证、所有元数据/未知值比较、引用数及 SQLite 完整性校验先完成，再原子发布小文件。正常升级/新式另存为不再依赖 Windows 对整个数据目录的改名，避开该发布失败路径。原始旧工程继续留在原位置。

不支持的触发器/虚表/未知版本等不能安全转换时会明确拒绝，不猜测转换，不带错数据继续打开。当前未声称所有历史格式/第三方扩展均可升级。断电、物理介质故障和任意第三方破坏不能靠软件承诺100%保证，尚未做相应耐久性实验。

## 菜单

文件菜单保留新建、打开、最近工程、保存、另存为、退出。其余归并为：

- 其他打开方式：已有目录工程、便携包、只读打开。
- 导入：文档、脑图、剪贴板收件箱。
- 导出：原图、选中原图、文档、脑图、兼容旧格式工程、便携包。
- 存储维护：无损整理对象、恢复未完成工程。

手动“转换当前工程”不再作为常规菜单项，因为打开旧文件已经强制引导转换；底层捕获保存接口保留，供兼容会话与相关回归使用。兼容旧格式输出统一在导出菜单，不与新式另存为使用同扩展名的两种选项混淆。

缺少入口但已有完整 `.prism.data` 时，恢复入口会先核对数据库和全部原件，再发布小入口。恢复仅承诺已提交的数据；取消前尚未提交的编辑不能凭空恢复。旧 `.incomplete` checkpoint 路径仍支持。不要自行删对象库或覆盖源文件。

## 画布修复

1. 默认画布点击不再被送到“全部素材”聚合页。
2. 图片记录从隐藏变为可见时，会让视图内容边界缓存失效。此前记录已加载且可见，重置仍得到旧空边界；现在会重新取得实际范围。
3. 点击普通画布会立即重置，分页几何到达后补定位，末批结束再覆盖该画布完整范围；切回已加载画布也会重置。首次工程落点也显式重置。
4. 聚合页面不再禁用“重置相机”动作；待布局完成时的重置请求在最终几何提交后执行，不把程序自己的 transform 更新误认成用户操作。
5. 用户在等待中主动改变缩放时，自动重置不覆盖新的缩放。没有素材的画布保持正常空态，不编造图片。

## 开发证据与范围

### 左栏类型化导出（2026-10-26 C1）

在左栏右键具体资源导出：文档直接选择 Word DOCX 或 PDF；脑图选择 XMind；画布选择“全部图片原件”或“全部素材原件”，再选择输出父文件夹。默认画布也提供导出，不需要先修改资源树。右键目标与当前激活页独立，选择位置期间工程/资源发生变化会拒绝旧请求。

图片原件模式不包含视频/模型，并在摘要说明；全部素材模式还查询未加载的视频/模型目录。新入口没有原件就明确失败，不拿预览图重编码冒充原件。画布PDF、脑图PDF及虚拟聚合结果的类型化导出尚未接通，不在左栏伪装可用。

文件夹/分区继续按资源树导出为目录或ZIP。新目录必须不存在，不合并覆盖；文件写入/取消失败不发布半个新目录，ZIP有错误不替换旧ZIP。文档和脑图单文件也先写临时目标，完成且未取消才发布。大型规划目前仍有O(N)元数据条目，原件已改为后台分块读写；不据此宣称十万级性能已通过。

### 日志与诊断（2026-10-26 新接通）

重启源码程序后，通过帮助菜单“日志与诊断…”打开窗口。“标记刚才的问题”可记录问题时间；可选填写操作/预期/实际，再点击“导出诊断包…”。只保存到用户选择的位置，不自动上传。普通日志只异步读取最近128 KiB，导出在后台完成，可关闭窗口取消收集。

ZIP包含当前仍保留的普通/追踪轮转日志、崩溃JSON与原生故障日志、运行环境、启动版本快照、当前磁盘关键源码hash及证据manifest。默认对路径、用户名和已知正文/凭据字段脱敏，不包含工程原件、完整配置、剪贴板或截图。脱敏是尽力识别，不能保证任意第三方自由文本里不存在个人信息；用户填写的问题描述明确包含在包中。

限制会写入包：单日志8MiB、日志总额32MiB、最多64个文件；截断/采集中变化/缺失文件明确标记，不能恢复已经轮转删除的内容。Windows事件、真正native栈、GPU、全库统计与设置白名单尚未自动采集，不能把该版本称为全部诊断覆盖完成。
