# Prism 0.4.0：材质库与 PBR 预览

## 本次内容

- 材质库入口、文件夹、网格/列表、标签、备注、全局搜索定位和多选原贴图导出。
- 右侧贴图槽位及逐槽通道选择，PBR 预览与平面/球体/圆柱体/立方体切换、独立通道查看。
- Babylon.js 官方 PBR 与 glTF 加载器复用；没有自写材质或 GLB 渲染内核。
- 画布瓦片裁剪、细节恢复、缓存目录复用、范围查询和资源树无效设置写入优化。
- 文档/脑图编辑器保存读取保护，后台保存的元数据及附件快照，Save As 源绑定和过期结果保护；文件读写期间保护项目生命周期。
- README 与截图更新为真实“测试.prism”项目副本，原项目和整套参考素材不在发布包中。

## 验证范围

发布前的逐文件去重回归为 183 文件、2857 通过、61 跳过、0 失败；这个数字来自首轮与针对修改文件的复跑，不是一次执行的单套成绩。另有真实大项目副本保存重开、2753 个画布源文件和 1221 个附件原始字节哈希校验，以及 300 真实材质、特殊效果、900 原贴图拖出验证。

## 已知限制

- 冷画布细节准备仍可能约 3 秒，设置落盘、首次 WebEngine 显示与材质缩略图生成仍可能延迟；不宣称卡顿全部解决。
- 61 项跳过包含旧 UI 契约、固定视频素材缺失、原生平台条件和可选 OpenImageIO；没有将跳过算成通过。
- SSS 为薄表面近似，不能保证任意 UE 母材质一致。UE 实际接收端及插件尚未交付验证。
- 画布图元的完整后台保存快照隔离仍需后续工作；已有文档/材质元数据和附件快照不等于整个场景的线程隔离。
- 模型库及 FBX/OBJ 自动转换仍在讨论阶段。
- 安装包未签名，主要验证 Windows 11 x64，使用 Release 的 SHA256.txt 校验下载文件。

更新前备份已有项目。安装包、对应源码和校验文件随同一版本发布。
