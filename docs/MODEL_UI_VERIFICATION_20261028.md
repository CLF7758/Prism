## 本轮发现与修正

1. **普通模式被三角边线污染**：旧 `highlight` 修改源 actor 的 EdgeVisibility，诊断通道也被打开边线。现将高亮放入独立、不可拾取的轮廓 actor；只有“材质＋边线”开启源边线，“纯线框”切换 representation。
2. **拆顶点让轮廓退化为布线**：真实 FBX 的 UV/法线接缝拆点，直接计算轮廓会把大量三角边界画亮。仅对派生轮廓拓扑精确焊接坐标，原几何、UV、法线、原文件不变。木雕仍有真实雕刻表面的内部几何轮廓，不能声称只剩屏幕外轮廓。
3. **法线允许错误单通道**：服务拒绝 normal 的非 RGB 设置，模型编辑器禁用这些选项。旧工程的 A 绑定通过真实 UI 改成 RGB 并持久化；不静默迁移数据库。
4. **关闭预览被算成崩溃**：工作进程正常发送关闭事件与 BYE；控制器只在 BYE 且退出码 0 时按正常退出处理，不消耗崩溃重试额度。服务清除原生活动场景，保留已验证的源映射；下次操作重新装载。非正常丢失仍撤销能力。
5. **重新打开遗漏当前高亮**：服务按模型和源修订保留选中的 binding ID，装载时发送给新进程；不沿用旧原生句柄。
6. **中间列表吞掉外部 FBX 拖入**：共享 MaterialCards 增加显式注入的本地文件拖入端口，模型库接到现有 import_paths；阻止 Chromium 文件导航；内部资产 MIME 仍交现有整理逻辑。目录枚举只在 drop，不在高频拖动路径。
7. **工具栏挤压**：分开资产操作与视图操作，并将计数独立成行。修正已有封面仍显示“预览尚未接入”。最后一项计数布局需在最终进程重开后复核。
8. **Tab 打断编辑**：输入控件与右侧检查器中的 Tab 用于字段提交和焦点移动，画布快捷键不再折叠正在使用的编辑器。涉及共享主窗口与材质库。
9. **预览/封面偶发不刷新有真实日志证据**：编辑线程与封面线程同时写固定 `.tmp`，产生 PermissionError/WinError 32。`presentation.py` 改为独立临时文件、完整写完后发布不可变缓存，并保护同进程同目标发布；派生 PNG 同样不再直接写读者可见的文件。对不支持硬链接的文件系统提供完整文件重命名回退。本修复后还需真实工程持续操作对照，不能用单元测试宣布偶发问题消失。
