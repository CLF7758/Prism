# Prism 0.3.11

这一版把视频下载放到画布中，并加入图片裁切和 PDF 导出。Windows 安装包包含运行环境、下载组件、截图组件和本地以图搜图模型，无需另装 Python 或 FFmpeg。

## 下载视频与图文

- 在画布上右键选择「下载视频」，在鼠标位置出现下载节点。粘贴网址或整段分享文字，回车即可开始。
- 节点标题可以拖动，显示下载进度；下载在后台运行，可以继续操作画布。完成后素材导入任务最初所在的画布，节点自动消失。切换画布不会把素材插错位置。
- 抖音图文先识别图片集，保留原图和附带的 Live Photo 视频，自动紧凑排列；不再把图文的空视频字段当成普通 MP4 下载。多素材可以一次撤销、恢复。
- 小红书使用 XHS-Downloader 与 Xhshow 的正常游客会话，修复页面可播放但下载器取不到正文的情况。会话仅保存在任务进程内存中。
- B站使用 bilibili-api-python。默认保护原始分辨率；平台只提供较低清晰度时，显示实际可用尺寸，由用户明确选择是否下载。合并音视频采用流复制，不二次压缩。
- B站 Opus／动态／专栏图片有独立识别路径。此路径通过上游返回结构回归测试，尚未用用户提供的真实图文链接验收，不宣称所有链接可用。
- 平台登录权限、地区限制、删除和风控仍可能导致失败；不会把封面或低清视频冒充原视频。本站之外的视频由 yt-dlp 处理。

## 画布与导出

- 图片右键「裁切图片」，四角和四边中点共八个圆点可拖动；回车确认、Esc 取消，支持撤销，原始文件保留。
- 画布、文档和脑图在原有导出窗口选择 PDF 格式，无需寻找新增的右键菜单。
- 未播放的视频使用首帧作为封面；右侧检查器封面居中。
