## 已实施

1. 模型库资源树旁显示“＋”，复用材质库的就地新建、重命名、稳定文件夹 ID 与目录树。模型文件夹可嵌套，点击／Enter 打开对应范围；工具栏“新建文件夹”接入同一路径。计数避开＋按钮。
2. 模型卡片、材质卡片多选后，可拖到同工程资源树中的同类文件夹，也可拖回对应库的根目录。目标高亮与悬停展开复用资源树；只改所属文件夹，不挪动、改写原件。模型跨页选择使用控制器的完整集合，不仅移动当前页可见的几个。
3. 模型列表 Delete 直接软删除当前选择，显示 8 秒撤销提示；不物理删除原始模型／贴图。编辑名称、搜索词、备注时，Delete 仍由文本编辑器处理。卡片的快捷键覆盖独立于画布删除动作，避免误删画布选中内容。本轮未新增全局回收站中的模型恢复入口。
4. 模型与材质卡片提供右键“重命名”和 F2。模型右侧标题改为名称编辑框；材质右侧复用已有名称框。只修改显示名称，主模型文件名、贴图路径和原件导出字节保持原样。
5. 材质默认拖动用于库内整理；原有拖贴图到 UE／外部软件的路径保留为 **Alt＋拖动**，卡片容器有对应提示。外部路径的文件准备、同名防冲突和原字节转交测试保留。

同一 `.prism` 内的根目录／子目录整理均允许。两个不同 `.prism` 之间不是同一组 ID：本轮未实现跨工程复制导入，不把“给另一个工程写入当前 ID”当成跨工程整理。用户提出的画布式同工程拖动不会受这个校验影响。
