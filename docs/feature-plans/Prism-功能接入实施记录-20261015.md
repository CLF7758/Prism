## 已实现

### 截图、桌面参考图
- 截图引擎复用 ScreenPinKit，固定提交 1c0dc5fa14a9ec99660fbb3bc6eade7d7d1c3f77；Qt5 单独运行，不混入 Prism 的 Qt6。
- 画布工具栏“截图”、插入菜单“屏幕截图”；全局 Ctrl+Alt+A，可在现有快捷键设置修改。快捷键占用时通过提示说明，退出释放注册。
- 框选后可选钉在桌面、送入画布、两者都要。画布图片可从工具栏或图像菜单钉出。
- 根据最新反馈，去掉画布右键独立“钉在桌面”和插入菜单“截图收件箱”入口。
- 桌面参考窗口改用 Prism 原有 DrawingToolbar、PrismPathItem 与画布橡皮擦逻辑，不再把 ScreenPinKit 的英文浅色标注工具栏呈给用户。
- 右键菜单中文；深色菜单使用 Prism ui_tokens；支持画笔、线型、两端箭头、擦除、复制、另存、送入画布。
- “图片透明度”提供 15%～100% 滑块；Ctrl+滚轮调透明度，普通滚轮缩放窗口。窗口透明度不改导出像素。
- 最多 20 张贴图、128 MiB 像素预算；截图收件数据最多100张或512MiB。
- 真实截屏助手→Prism导入→撤销重做已验证；全局热键在 Windows 注册、消息回调和注销已验证。真实多屏混合DPI截图仍需人工验收，上游拼接方式存在限制。

### 本地以图搜图
- 搜索输入框右侧入口；选文件、拖入、粘贴、对画布素材查找相似图片。结果复用现有无限素材画布。
- 算法直接使用 OpenCLIP 2.26.1（ViT-B-32/openai）与 FAISS 1.12.0；桥接、UI与进程管理由 Prism 实现，不是自研相似度算法。
- 模型与索引独立后台进程；首次下载模型后不需要 API Key，检索不上传图片。
- 模型353,976,522字节，SHA256 40d365715913c9da98579312b702a82c18be219cc2a73407c4526f58eba950af，已校验。
- 修复 Windows 隔离进程忽略 PYTHONIOENCODING 导致的 GBK/UTF-8 通信失败；启动桥接明确设置三条标准流为UTF-8。
- 修复搜索框范围/筛选控件无布局、重叠盖住输入框的问题。
- SQLite按内容哈希缓存512维向量，限定最多10万向量/20万别名；验证缓存维度、数值和归一化。
- 用用户最新桌面工程的数据库副本对2,742张有效图片实际检索，缺失0；用户导出的原图素材2451排第一，得分1.0。CPU首次建索引总耗时224.9秒，第二次同进程缓存查询约0.484秒。真实首次成本尚不是瞬间完成；进程冷启动和新工程读取仍有额外费用。

### 网站视频下载
- 插入菜单“网站视频下载”，调用 yt-dlp 2026.8.19；FFmpeg/FFprobe做合并与完整性检查；未编写网站视频解析器。
- 支持分享文案提取网址、处理转义字符和HTML实体、清理B站跟踪参数；小红书短链登录跳转保留作品地址交给yt-dlp处理。
- 最多2个任务、等待队列20个、历史20项；FFmpeg处理单实例互斥；取消后台进程会结束其子进程树。
- 明确选择Chrome/Edge/Firefox后才让yt-dlp使用浏览器登录状态，默认不读取；也支持Netscape Cookie文件。
- 任务下载完成后可将视频嵌入目标画布或打开现有提帧对话框；提帧复用现有最优排列。工程或目标画布改变时不会误导入。
- 嵌入视频改用分块文件/SQLite BLOB读写，避免把完整视频批量堆到内存；原始视频保存→重开→再次保存的字节一致性已测试。
- yt-dlp从本机HTTP下载真实合成MP4并通过FFprobe检查已验证。
