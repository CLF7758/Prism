Prism 面向绘画、游戏美术、场景设计和建模。你可以在一个本地工程中整理参考、收存模型与贴图、预览材质效果、写制作笔记，并把需要的原始素材导出给其他软件。

**图片、画布、脑图、文档、材质和模型都是独立资源。** 左侧的全部素材、未分类、未标签、最近使用与回收站，是同一份工程资源的不同浏览口径。文件夹用于分类，具体画布用于自由排布；两种浏览方式各司其职。

> 本页实景截图来自用户指定的真实 Prism 工程。只公开软件界面截图，不公开工程数据库、原始素材、账号或个人配置。画面中参考作品及素材的版权属于各自权利人。

## 功能总览

| 工作区域 | 可以做什么 |
|---|---|
| 无限画布 | 拖入图片和视频，自由排布、缩放、旋转、翻转、裁剪，配合文字、画笔和箭头整理参考 |
| 统一素材浏览 | 在网格中浏览工程资源，搜索、过滤、多选、缩放卡片，双击打开原始位置 |
| 文件夹与标签 | 五个资源分区的文件夹层级、移动分类、就地重命名，以及标签、备注、评分 |
| 材质库 | 保存 PBR 原始贴图与通道绑定，以材质球卡片和大预览查看效果 |
| 模型库 | 导入 FBX、OBJ、GLB、glTF，管理模型槽位、材质贴图、封面和原件导出 |
| 文档与脑图 | 富文本笔记、图片、思维导图，保存在同一工程，提供对应导入导出入口 |
| 参考采集 | 屏幕截图、桌面贴图、浏览器图片收集、本地视频和下载节点 |
| 查找与整理 | 全局文字搜索、本地以图搜图、重复图片检查、最近使用和回收站 |
| 工程管理 | 新建、打开、保存、另存为、Eagle 资料库导入，以及自动保存与恢复入口 |

## 无限画布：从素材到参考板

![真实工程：无限画布与素材检查器](docs/images/v0.5.0-real-canvas.jpg)

- 多画布管理：不同主题、镜头或制作任务可以各用一张画布，再放进文件夹。
- 图片自由移动、缩放、旋转、翻转和裁剪，支持多选和排列整理。
- 用文字、画笔、直线和箭头做构图、色彩和制作分析。
- 调整画布缩放、回到中心或适配内容；也可把参考图钉在桌面。
- 选中图片后，右侧检查器显示预览、名称、备注、标签、评分、所在画布与文件夹路径、基本信息、颜色分布和直方图。
- 曝光、通道和伪彩等图片检查工具用于观察素材，原始文件与检查预览分开管理。

## 素材列表、目录与全局查找

![真实工程：素材网格和目录分类](docs/images/v0.5.0-real-assets.jpg)

### 五个统一入口

- **全部素材**：浏览工程中的图片、页面、材质与模型。
- **未分类**：查找尚未放入相应分类位置的资源，不局限于图片。
- **未标签**：查找没有有效标签的资源。
- **最近使用**：按工程保留最近 100 项，再次使用更新顺序，新项目会顶替最旧项。
- **回收站**：浏览软删除资源，并通过恢复或永久删除操作处理。

### 文件夹浏览与操作

画布、脑图、文档、材质库、模型库都有各自的文件夹层级。文件夹点击进入列表；点击具体画布才进入无限画布，文档和脑图也在打开具体页面后才进入编辑器。

- 文件夹层级线、折叠箭头和当前项定位帮助辨认归属。
- 文件夹内的图片查询限定在所属画布范围，不以全工程候选代替文件夹内容。
- 支持 Ctrl 多选、Shift 范围选择、拖动移动和“移动到…”目标选择。
- 资源名称支持相应列表中的 F2 与双击名称就地重命名。
- 网格提供卡片尺寸滑块、加减按钮与 Ctrl＋滚轮缩放。
- 单击图片查看完整检查器；点击“所在画布”或双击图片，跳转到来源位置。

### 搜索与筛选

全局搜索覆盖图片资料、页面、材质和模型，并可定位到实际资源。结合类型、标签和评分筛选缩小范围。以图搜图使用本地模型与索引，重复图片检查帮助整理相同或相似内容；它们与普通文字搜索是不同工具。

## 材质库：管理贴图，也查看 PBR 效果

![真实工程：材质卡片与贴图管理](docs/images/v0.5.0-real-materials.jpg)

- 用材质球卡片管理材质，支持目录、名称、标签、备注和原始贴图导出。
- 贴图槽包括颜色、法线、粗糙度、金属度、AO、透明遮罩/透明度、自发光、SSS 和置换。
- 添加、拖入、替换、移除贴图，查看缩略图、选择通道、启用/停用并调节数值。
- 选择 RGB、R、G、B、A 通道；ORM 等打包贴图可在多个相应槽位复用。法线按完整 RGB 数据处理。
- 提供透明判定、裁切阈值、颜色图 Alpha 忽略选项及 DirectX/OpenGL 法线约定。
- 球体、平面、圆柱体、立方体预览及独立大预览，支持查看不同材质通道。
- 滑块在 0～1 之间调节，1 位于最右端；需要更高强度时可在旁边数值框输入。

**材质库与模型库复用贴图槽控件、参数规则和 Babylon.js 预览链路。** 二者使用同一份工作室 HDRI，目前光照强度和曝光均为 1.0。

SSS 与置换提供贴图资料管理；预览的支持程度与真实渲染器效果分开，不承诺完整体积散射、真实厚度求解或几何细分置换，也不等同于 UE 的最终材质效果。

## 模型库：模型、槽位与贴图一起管理

![真实工程：模型库和模型材质](docs/images/v0.5.0-real-models.jpg)

- 支持 **FBX、OBJ、GLB、glTF** 模型导入，保留模型与原始依赖文件。
- 模型卡片展示名称与封面，按文件夹、标签、备注组织。
- 单击模型后检查材质槽位，双击打开模型预览窗口。
- 材质卡片代表模型实际槽位；从材质库选择材质，替换当前槽内容。
- 模型材质采用共用贴图管理组件，处理颜色、法线、ORM 等贴图与参数。
- 在预览窗口旋转、缩放、查看不同模式，回到正面，并将当前视角设为封面。
- 原件导出包含模型与对应贴图，放进同一个导出文件夹。
- 提供模型和贴图向外拖出以交给其他软件导入的工作流，包括 UE 内容浏览器。**不自动创建 UE 材质球或母材质，也不保证每个引擎版本对所有源格式的导入结果完全相同。**

Prism 是资产库与参考工具，侧重资料管理和预览，不替代 DCC 建模、游戏引擎或完整材质编辑器。模型封面、预览和最终引擎渲染可能因模型 UV、切线、贴图定义及引擎设置而不同。

## 文档与脑图

- 在工程内保存富文本制作笔记、图片与结构化内容。
- 用脑图梳理场景、镜头、任务和研究主题。
- 文件夹中以页面卡片展示，封面以页面标题辨认，不为列表预览启动正文编辑器。
- 提供各自的文件导入、导出和 PDF 等输出入口；复杂内容及外部格式应按实际文件核对兼容性。
- 文档、脑图与画布一样参与工程资源浏览和全局搜索。

## 截图、视频与外部资料收集

- **屏幕截图**：区域截图可以送入画布或作为桌面参考贴图。
- **桌面贴图**：将选中参考图钉在桌面，并调整透明度等显示方式。
- **本地视频**：导入、封面缩略图、播放、视频画面提取和参考整理。
- **下载节点**：通过独立组件处理支持平台的图片或视频资料；部分平台需要用户自己的登录状态，成功与否受平台接口、权限和网络影响。
- **浏览器收集扩展**：配合本地接收服务收集网页图片，见 [browser-extension](browser-extension/README.md)。

## 导入 Eagle 资料库

从菜单选择 **导入 Eagle 资料库…**，把已有 Eagle 资料转入 Prism：

- 保留 Eagle 文件夹的层级关系，将目录内容组织成对应画布及目录结构。
- 导入图片与视频资料，并带上可读取的名称、备注、标星和标签。
- 已经打开 Prism 工程时，导入到当前工程，不再要求另选新工程位置。
- 未打开已保存工程时，可以走创建新工程的转换流程。
- 读取 Eagle 数据，不改写原 Eagle 资料库；不支持的文件类型会跳过并反馈。

## 工程保存、原件与恢复

Prism 的当前工程采用 **`.prism` 入口加 `.prism.data` 数据目录**的管理式存储。入口、元数据数据库与原件对象目录共同组成工程；搬迁或备份时应作为整体处理。旧版项目通过相应兼容/转换入口打开。

- 新建工程可以选择位置，提供保存、另存为和最近工程入口。
- 原始素材与缩略图、预览缓存分开保存，原件导出不拿缩略图代替。
- 图片、模型、材质原件保留自身格式；预览解码不会把原文件覆盖成另一种格式。
- 自动保存、恢复记录与异常后恢复入口用于降低意外退出的损失；恢复范围以已经完成的保存/恢复记录为准，不能替代用户备份。
- 日志和诊断工具记录功能错误、后台任务及性能事件，便于定位问题。

如果旧项目已经没有原始文件、只剩缩略图，Prism 无法凭空恢复丢失的原件。

## 安装和运行

1. 到 [GitHub Releases](https://github.com/CLF7758/Prism/releases/download/v0.5.0/Prism-Setup-0.5.0-windows-x64.exe) 下载 **Prism-Setup-0.5.0-windows-x64.exe** 与同页 `SHA256.txt`。
2. 安装到当前 Windows 用户目录，按需创建桌面快捷方式。
3. 打开已有工程，或新建工程后导入素材。
4. 用 `Ctrl+S` 保存；升级前建议备份自己的整个工程。

**完整安装包包含主程序、Qt/WebEngine、图像与视频依赖、截图组件、本地以图搜图模型和视频下载组件。** 无需另外安装 Python。网络平台功能仍需要网络及相应权限；3D 预览需要可用的 GPU/WebGL 环境。当前发布面向 Windows x64，主要使用 Windows 11 验证；安装包未进行商业代码签名，可用发布页 SHA-256 校验。

0.5.0 更新涉及模型库、共享贴图管理、Eagle 导入、管理式工程存储、统一资源列表、文件夹交互及多项退出和预览问题修复。大型工程初次加载、首次网页预览和缩略图生成仍受硬件与素材规模影响，不将开发测试通过描述成所有设备都已全面验收。详见 [版本说明](docs/RELEASE_0.5.0.md)。

## 从源码运行与参与开发

需要 Python 3.12：

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements/windows-lock.txt
.\.venv\Scripts\python -m pip install --no-deps -e .
.\.venv\Scripts\python -m prism
```

截图、以图搜图与平台下载使用独立组件；源码环境按 `tools/setup_*_component.py` 准备，完整安装包已经包含。构建步骤见 [Windows 打包说明](packaging/README.md)，复用与扩展约定见 [架构说明](docs/ARCHITECTURE_EXTENSION_GUIDE.md)。
