# Embedded renderer

Babylon.js and babylonjs-loaders 8.26.0 are unmodified official npm builds,
licensed Apache-2.0. See LICENSE.md, ORIGIN.json and LOADERS-ORIGIN.json.

studio.env is from BabylonJS/Assets contributors, under CC BY 4.0.
See ENV-LICENSE.txt and ENV-ORIGIN.json for upstream commit and SHA-256.
The application uses it for lighting; no network fetch is needed.

../default-sphere.png is a screenshot generated by this embedded Babylon
renderer with the bundled studio environment and default material. It is
a neutral empty-material placeholder, not a user texture or UE screenshot.

Prism's render.js configures the engine's built-in materials, camera, mesh,
displacement and glTF loader. It contains no custom PBR or SSS shader.
