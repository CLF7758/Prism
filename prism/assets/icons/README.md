# Prism UI icons

The interface SVGs in this directory were drawn for Prism. They are original
project assets, not copied from Eagle, PureRef, or a third-party icon pack.
They follow a 24 × 24 viewBox with round caps/joins and a 1.75 unit stroke.

The icons are distributed under the same GPL terms as Prism. `radio-dot.svg`
is a filled indicator and therefore does not use the outline stroke rule.
`check.svg` is white so it remains legible over the selected control colour;
`star-filled.svg` uses the warning token colour to show an active rating.
